# Shamsad & Khushboo — Interactive Wedding Invitation
Responsive HTML/CSS/JavaScript recreation inspired by the uploaded reference video.

## Run
Open `index.html`, or run `python3 -m http.server 8000` from this folder and visit `http://localhost:8000`.

## Included
- Animated envelope and wax-seal opening interaction
- Invitation cover and wedding introduction
- Scratch-to-reveal card
- Countdown to Nikah date
- Nikah/Walima program timeline, venue directions, invitation cards
- Wish form that opens WhatsApp with a prefilled message
- Mobile-first design

## Please check before publishing
- Confirm the WhatsApp contact number and map links.
- The video shows music, but no music file was provided. The music button is a placeholder until you add an audio file.
- The supplied card images are shown as provided. Countdown uses 31 Oct 2026, India Standard Time.
- The RSVP form does not save data to a database; it opens WhatsApp.
